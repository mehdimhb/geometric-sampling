Read-only snapshots of the existing package, including the user’s current uncommitted research changes. The originals were not edited. Source filenames have a .txt suffix so snapshots do not enter the simulation executable-source fingerprint or shadow installed modules. To recreate a source checkout, copy the tree to a separate directory and remove the final .txt suffix from source and pyproject filenames. Install that checkout with pip install -e, then run the study from its repository root with prescribed_sip present.
